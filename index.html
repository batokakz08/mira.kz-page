Кибби ещё не определён по фото.

Для Кибби нужно фото в полный рост, прямо, без свободной одежды, которая скрывает линию. Если селфи только лицо, загрузи отдельное фото тела ниже. Тип считается по признакам линий; это ориентир, не оценка тела.

Фото тела для Кибби · необязательно

Голова, плечи, бёдра и стопы целиком, прямо, в облегающей одежде. Фото используется только для Кибби — не для цвета, не для AI-образов и не сохраняется на сайте.

Силуэт и мерки (необязательно)

Силуэт уточняет длины, посадку и точку талии. Кибби отвечает за ткань, детали и масштаб. Это ориентиры, не правила.

Рост и вес нужны только для фото: помогут показать реальный масштаб тела. В тексте образов они не появятся.
